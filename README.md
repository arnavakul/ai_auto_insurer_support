"# ai_auto_insurer_support"

An auto insurer wants to speed up claim filing. Customers describe their accident andupload supporting documents — police reports, repair estimates, photos. The assistantmust gather a complete claim file, spot when a document is unusable or clearly the wrongfile, and politely request replacements. If the details in the documents don't match what thecustomer said (like different accident dates), the assistant should raise it as a neutralquestion, never an accusation. The finished claim should be organized, complete, and ready for an adjuster
